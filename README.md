# 收工记

收工记是一款桌面工时记录工具。工作时，用快捷键开始、切换或暂停计时。收工时，按天查看时间线和各事项的累计工时，整理好后就能复制成一份收工清单。

[查看下载与版本说明](https://github.com/aliang-creator/ShouGongJi/releases)

macOS（Apple 芯片）打开 `.dmg` 安装。Windows x64 下载对应的 `.zip`，解压后运行其中的 `.msi`。

## 记一件事

按下快捷键，输入事项名称并回车。正在计时的话，回车会结束上一段并开始新事项。当天回到同一事项时，可以从「最近事项」再次开始，收工页会把分开的时间段汇总起来。

| 操作 | macOS | Windows |
| --- | --- | --- |
| 唤醒输入框，开始或切换计时 | Ctrl + Shift + 空格 | Ctrl + Alt + 空格 |
| 暂停计时 | Ctrl + Shift + P | Ctrl + Alt + P |

主窗口最小化后，计时浮窗会留在桌面上，显示当前事项和已计时长。

## 收工时看一眼

打开「收工页」，可以在「时间线」按顺序查看做过什么，也可以在「事项汇总」查看每件事一共花了多久。忘记计时可以补录，已有时间段也能编辑。点「复制清单」即可把当天记录带到日报或工作日志里。

![收工页的事项汇总，展示一天的总工时和分项明细](screenshots/day-review.png)

## 对接阿里云云效

需要在云效登记工时的话，从「收工页」打开「云效设置」，按界面里的「帮助」配置连接。配置完成后，可以把本地事项关联到已有任务，也可以新建任务，再核对并提交实际工时。日常计时记录保存在本机，提交时会把所选任务和工时同步到云效。
